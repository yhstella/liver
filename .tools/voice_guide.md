# drshin.kr 자연 톤 가이드

이 문서는 사이트의 모든 글이 따라야 할 톤 가이드다. 작성자(신현재, 서울대학교병원 소화기내과·간암센터)가 진료실에서 환자에게 설명하듯 쓴 글로 읽혀야 한다. AI 도구로 작성됐다는 단서가 한 군데라도 보이면 의료정보 사이트로서의 신뢰가 흔들린다.

Antigravity·Codex·Claude Code 등 어떤 도구가 작업하든 이 가이드를 따른다.

---

## 절대 피해야 할 패턴 (AI tells)

### 구조

- **TLDR / 핵심 요약 / 한 문단 요약 박스를 모든 페이지가 가짐** — 박스는 페이지당 0~1개. 정말 강조가 필요한 한 곳만. 결론은 본문 첫 문단에 자연스럽게 녹임.
- **"처음 [X] 받으신 분께" / "오늘 할 일 3가지" / "본인 시점 가이드"** 같은 산업식 진입 박스 — 사용 금지. 같은 내용을 본문에 진료실 어투로 풀어 씀.
- **체크리스트 박스 남용** — 외래에서 환자에게 진짜 종이에 적어 주는 항목 한 묶음(많아야 1개)만. 거의 모든 페이지가 체크리스트를 가지면 AI 흔적.
- **BACKGROUND·KEY FINDINGS·INTERPRETATION·CLINICAL TAKEAWAY·BOTTOM LINE** 정형 헤더 박스 — 한국 의사 진료실 노트가 아님. 학술 review article 양식. 사용 안 함.
- **같은 결론을 TLDR·KEY FINDINGS·BOTTOM LINE 세 번 반복** — 한 글에 결론은 한 번. 본문에 한 번 명확히 쓰면 충분.
- **SVG 도식이 모든 update 글에 비교막대·타임라인 형식으로 등장** — 도식은 정말 그림이 도움 되는 곳에만. 정형 패턴 X.
- **모든 update 글이 BOTTOM LINE → SNUH 임상시험 안내 → References → 관련 글 → tag-row → author-mini 동일 푸터** — 일률화 X.
- **"본원(서울대학교병원)에서도 ... 임상시험 몇 건이 ..."** 정형 단락 — 사용 금지. 임상시험 안내가 필요하면 본문에 자연스럽게 한 문장 ("이런 환자분 중에는 서울대병원에서 진행 중인 신약 임상시험을 안내드릴 때도 있어요" 정도) 또는 별도 안내 페이지로.

### 표현

- **"환자분"이 한 문단에 3회 이상** — 1~2회로 자연스럽게. 나머지는 주어 생략 또는 "이런 경우 / 이때 / 보통은"으로.
- **"외래에서·임상에서·권고합니다"** 반복 — 가끔 섞이는 건 자연. 매 단락에 등장하면 AI 티.
- **"결정적입니다·사실상·절대·매우 드뭅니다"** 같은 강조어 빈출 — 한국 의사는 보통 "그렇게 보입니다·대개·드물게" 식으로 부드럽게 hedge.
- **약어 첫 등장 시 "(한글 풀이)" 일률 처리** — HBeAg·ALT·HCC 같은 일상 약어는 그대로 두는 게 자연. 환자가 진짜 헷갈릴 새 용어(예: "Bragg peak", "anti-CD20")만 한 번 풀어 씀. 모든 약어 일률 풀이는 AI 흔적.
- **"~입니다" 일변도** — 진료의는 가끔 "~해요·~죠·~네요" 섞음. 다 "~입니다"로만 쓰면 기계적.
- **"다만·그러나·또한·따라서"가 매 단락 시작** — 접속어 빈도 줄이고 흐름을 본문 자체로.
- **evidence를 매번 "phase 2·phase 3·primary endpoint·secondary endpoint·surrogate vs hard endpoint"로 명시** — 환자용 사이트라 학술 용어 절제. "최근 NEJM에 보고된 결과 / 대규모 임상시험 한 건에서" 정도로.

### 서식

- ▶●◆✓✗ 같은 marker — 모두 제거. 일반 본문 흐름으로.
- 한 문단에 `<strong>` 5회 이상 — 강조가 강조의 의미를 잃음. 1~2회로.
- caption·표 헤더가 모두 같은 폰트·색조 스타일 — 정형 패턴.

## 따라야 할 것 (자연 톤)

### 어조

- 한국 의대 졸업한 의사가 외래에서 환자에게 설명하는 자연스러운 어조.
- "~합니다" 정중함이 기본, 가끔 "~해요·~죠"가 섞이는 게 자연.
- 의학 용어는 진료의가 평소 쓰는 만큼만. 다 풀어쓰면 어색.
- 결정적 단언 절제. "~인 편입니다 / 보통 그렇게 봅니다 / 대개는 / 일반적인 흐름입니다" 같은 자연스러운 hedge.

### 구성

- 결론은 본문 첫 1~2문장에 녹인다. 박스로 빼지 않는다.
- 한 페이지에 박스는 0~1개. 정말 필요한 경우만.
- evidence는 본문에 흐르듯 인용. 학술지 양식 그대로 옮기지 않는다.
- 의사 본인의 외래 경험·진료실 일화를 자연스럽게 한 문장 정도. ("외래에서 이런 질문을 종종 받는데" / "저는 보통 이렇게 설명합니다") 너무 잦으면 다시 AI 티.

### 한국 진료 맥락

- 한국 보험·약가 맥락이 자연스러우면 본문에 한 줄.
- 약 이름은 한국 상품명 우선 (위고비·마운자로·하보니·엡클루사 등). 영문 generic name은 괄호 안에 짧게.
- "외래·진료의·6개월 검진" 같은 한국 의료 표현으로 흐름.

## 작업 시 self-check

새 글 작성 / 기존 글 수정을 끝내기 전에 본인이 쓴 글을 다음과 같이 점검한다:

1. **TLDR 박스, 진입 박스, 체크리스트 박스, BOTTOM LINE 박스 합계가 2개를 넘는가?** → 줄인다.
2. **"환자분"이 한 페이지에 10회 이상 등장하는가?** → 4~6회 정도로 줄인다.
3. **"결정적·사실상·절대" 같은 강조어가 3회 이상인가?** → 자연 hedge로 바꾼다.
4. **모든 약어가 첫 등장 시 (한글 풀이)로 묶여 있는가?** → 환자가 진짜 헷갈릴 용어만 풀이.
5. **결론이 TLDR + 본문 + BOTTOM LINE 세 곳에 같은 말로 반복되는가?** → 한 곳에만.
6. **본문에 의사 본인의 시점이 느껴지는 한 문장이 있는가?** → 없으면 한 문장 자연스럽게.
7. **본문을 소리 내어 읽었을 때 정형 보고서 같은가, 진료실 설명 같은가?** → 후자가 되도록.

## 단상(`단상/`) 작성 원칙 — 다른 페이지와 규칙이 다르다

`단상/` 아래 글은 **의학 정보 페이지가 아니라 신현재 본인의 글**이다. 앞의 톤 규칙 중 "hedge하라", "강조어 절제하라", "감정 표현 자제하라"에 해당하는 항목은 **여기서는 적용하지 않는다.**

- **공감 능력을 최대치로.** 환자와 보호자가 읽고 "이 사람은 내 사정을 안다"고 느껴야 한다. 진료실에서 못 한 말을 하는 자리다.
- **인간미 있는 말투.** 망설임, 자책, 허탈함, 기쁨을 그대로 쓴다. 결론을 정리해 주지 않아도 된다. 답이 없는 채로 끝나는 글도 좋다.
- **1인칭.** "저는", "제가"를 피하지 않는다. 다른 페이지에서는 절제하지만 여기서는 자연스럽다.
- 박스·표·체크리스트·References 쓰지 않는다. 그냥 문단으로 흐르는 글.
- 의학적 hedge를 억지로 넣지 않는다. 다만 **치료 권고로 읽힐 문장은 쓰지 않는다.** 특정 약·용량·검사 주기를 권하는 내용이 필요하면 해당 주제 페이지로 링크를 건다.
- 의료 disclaimer 박스를 붙이지 않는다(자동 주입에서도 제외되어 있다). 대신 랜딩에서 "의학 정보가 아니다"라고 한 번 밝힌다.

### 다룰 만한 것

- 외래 진료의 현실 — 3분 진료, 가벼운 병에 시간을 못 쓰고 중한 병에 쓰려는 배분, 그 사이의 내적 갈등
- 치료 반응이 좋았을 때와 나빴을 때
- 금주나 행동 변화를 끝내 이끌어내지 못하고 환자가 나빠졌을 때의 허탈함
- 개인적인 경험 (직접 약을 써 본 이야기 등)

### 절대 금지

- **본인이 겪지 않은 일을 겪은 것처럼 쓰지 않는다.** 단상의 가치는 전부 진짜라는 데서 온다. AI가 그럴듯한 일화를 지어내면 이 섹션은 존재 의미가 없다.
- 특정 환자를 식별할 수 있는 내용. 사람을 쓸 때는 여러 사람의 공통된 모습으로 뭉뚱그린다.
- AI 초안은 **감정의 골격과 문장 리듬까지만** 잡고, 실제로 있었던 일·본인의 판단·느낌은 반드시 본인이 채운다. 채워지기 전에는 noindex 초안으로 둔다.

## 케이스(증례) 작성 원칙

`케이스/` 아래 글은 **표준 진료 흐름을 설명하기 위해 전형적인 상황을 구성한 교육용 예시**다. 실제 환자의 차트가 아니다.

- disclaimer는 반드시 "구성한 교육용 예시이며 특정 환자의 기록이 아니다"라고 정직하게 쓴다. **"환자 정보를 익명화 처리했다"·"식별 정보를 변경했다" 같은 표현은 금지** — 실제 환자가 있었다는 거짓 인상을 주고, 신뢰를 가짜로 만든다.
- 케이스 본문에 의사 본인의 1인칭 일화("제가 본 환자", "기억에 남는 환자분")를 창작해 넣지 않는다. 구성 사례를 실제 경험처럼 포장하면 안 된다.
- 수치는 교과서적 전형값을 쓰되, 그것이 실제 측정값인 양 서술하지 않는다.
