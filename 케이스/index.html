간암 케이스 모음

외래에서 자주 만나는 간세포암(HCC) 임상 시나리오를 가상 환자로 풀어낸 교육 케이스입니다. 진단 6편 + 치료 9편. 표준 가이드라인의 임상 결정 흐름을 시나리오로 따라가는 방식이며, 실제 환자 정보가 아닙니다.

진단 케이스

CASE 01

건강검진에서 우연히 발견된 1cm 결절

50대 남성, 무증상, B형간염 검사력 모름

 CASE 02

B형간염 정기 검진에서 새로 발견된 2cm 결절

55세 여성, 만성 B형간염 10년 추적 중

 CASE 03

AFP만 올라가는데 영상은 정상

60대 남성, B형간염 환자, AFP 350

 CASE 04

LI-RADS 3 모호한 결절 — 추적인가, 정밀인가

58세 여성, B형간염, LR-3 결절 발견

 CASE 05

PIVKA-II 1500인데 와파린 복용 중

70세 남성, 심방세동·B형간염, PIVKA-II 위양성?

 CASE 06

MASLD 추적 중 발견된 간세포암

65세 비만·당뇨, B/C형 음성, 5년 추적 중 새 결절

치료 케이스

CASE 07

단일 3cm 종양 — 절제와 고주파열치료술 사이

60세 남성, BCLC A, 두 옵션이 비슷할 때

 CASE 08

BCLC A 다발성 — 3개 결절·각 2cm 이하

55세 여성, 다발성 RFA

 CASE 09

Child-Pugh B + 단일 4cm — 절제 어렵고 이식 평가

58세 남성, 비대상성 간경변 + HCC, LDLT 평가

 CASE 10

BCLC B 다발성 — TACE 1차

67세 남성, 4개 결절 양엽, Child-Pugh A

 CASE 11

8cm 큰 종양 — TACE + SBRT 결합

62세 남성, BCLC B 큰 단일 종양

 CASE 12

문맥 침범 BCLC C — atezo+bev 1차

55세 남성, 문맥 분지 침범, 면역치료 시작

 CASE 13

정맥류 출혈 이력 + BCLC C — STRIDE 선택

63세 남성, 베바시주맙 회피, durva+treme

 CASE 14

큰 종양 다운스테이징 → 이식 후보 전환

57세 남성, 7cm 종양 → TACE+SBRT → 이식

 CASE 15

절제 2년 후 새 결절 — 재발 결정 흐름

65세 여성, 첫 절제 후 2년 시점 새 결절 1개

모든 케이스는 교육 목적의 가상 환자 시나리오이며, 실제 환자 정보가 아닙니다. 임상 결정은 표준 가이드라인의 예시이며 개별 환자에 그대로 적용되지 않습니다.
