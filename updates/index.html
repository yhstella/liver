최신 지견 · Updates

의료진·전공의 대상의 짧은 노트입니다. 환자·일반인 대상 가이드와 톤·구조가 다릅니다 (배경 → 방법 → 결과 → 한계 → 임상 함의). 인용·DOI/PMID·가이드라인 출처를 명시합니다.

대상 독자 일반 독자께서는 홈의 시리즈 1–5의 환자용 가이드를 권합니다. 본 섹션은 임상에 반영할 신규 근거의 짧은 노트가 중심입니다.

아직 게시된 노트가 없습니다

곧 첫 노트가 올라옵니다.

예정 주제 (안):

AASLD 2026 MASH 가이드라인 update · resmetirom 장기 추적 · HBV functional cure 임상 진행 · HCC 면역치료 1차 옵션 변화 · KASL 2025 간암 가이드라인

노트 표준 형식

  1. 한 문단 요약 — 왜 중요한가, 임상 함의 한 줄
  2. Background — 직전 근거·표준치료
  3. Methods — design / n / primary endpoint
  4. Findings — 핵심 수치 1–3개
  5. Critique — 한계, 적용범위, 일반화 가능성
  6. Bottom line — 외래·임상에 어떻게 반영할지
  7. References — DOI/PMID 직접 링크

본 섹션의 노트는 의료진·전공의를 대상으로 한 요약이며, 진료 결정의 단일 근거가 되지 않습니다. 개별 환자 적용은 각 의료진의 판단·해당 기관 가이드라인을 따릅니다.
